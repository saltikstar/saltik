# Elite Dental Clinic — единая система для постепенного редизайна

## Характер
Современная, спокойная, профессиональная стоматология. Композиционные принципы присланных референсов: крупная ясная типографика, много белого пространства, асимметричная сетка, естественные фотографии, точные отступы и тонкие разделители. Не копировать референсы буквально.

## Цвета — подтверждены для этого проекта
- Основной фон: **белый** `#ffffff`. **Не использовать бежевый как фоновый цвет.**
- Основной акцент — **золотой из фирменного оформления** `#c49a44`.
- Более тёмный золотой для текста и CTA: `#946c21`.
- Заголовки: `#14171b`.
- Основной текст: `#44484b`.
- Второстепенный: `#6e7275`.
- Линии: `#e5e7e9`.
- Нейтральный технический плейсхолдер до получения фото: `#f4f5f6`. Не подменять его чужим портретом.

## Текст, сетка и UI
- **Шрифт:** только шрифт, настроенный в Tilda; внутри T123 использовать `font-family: inherit`. Не подключать Arial, Georgia, Google Fonts или кастомный `@font-face` для отдельных блоков.
- Контейнер до 1240px, desktop-композиция 2 колонки, на мобильном — 1 колонка.
- Заголовки большие, но не громоздкие; главный смысл — на первом экране.
- Кнопки — контрастное тёмное золото с белым текстом; никаких бездействующих CTA.
- Разделители тонкие, без тяжёлых теней, псевдо-3D и лишних аккордеонов.
- Фото специалистов — настоящие, согласованные; до получения снимка показывать подписанный плейсхолдер.
- Фотоколлаж — **прямые элементы `<img>` внутри CSS Grid**, без обёрток `<button>`, `<figure>`, `<a>` и без модального просмотра, если пользователь не просил.

## Секции
- `about-block.html`: блок «О клинике», коллаж и цитата основателя.
- `gnathology-hero.html`: первый экран врача-гнатолога Атаманова Азамата Болатбековича. В ожидании его профессионального фото.
- Следующие секции (симптомы, описание диагностики и др.) проектировать отдельно, не перегружая первый экран.

## Проверка перед запуском
Проверять 360 / 390 / 768 / 1280 / 1440px, наследование шрифта Tilda, контраст, доступность с клавиатуры, реальную кнопку записи, загрузку изображений и работу после публикации в Tilda. Наличие проверенного локального предпросмотра не означает, что код уже опубликован на рабочем сайте.
