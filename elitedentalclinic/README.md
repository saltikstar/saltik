# Elite Dental Clinic — «О клинике»

Единственный блок: описание клиники, **коллаж фотографий с обучения** и **цитата основателя** с маленьким круглым портретом. Дополнительных преимуществ, карточек услуг и CTA нет.

## Файлы

- `index.html` — полноценная страница предпросмотра блока.
- `about-block.html` — самодостаточный код блока для вставки в Tilda (T123).

## Импорт в Tilda

1. Откройте `about-block.html`, скачайте код через **Raw / Download**.
2. На странице Tilda добавьте **Другое → T123 HTML-код**.
3. Полностью замените предыдущую версию кода; скопируйте весь `about-block.html` (CSS, HTML и JS).
4. Сохраните, опубликуйте и проверьте опубликованную страницу.

**Изображения встроены** в HTML в WebP — дополнительных файлов или ссылок не нужно. Для основной вёрстки используется шрифт, заданный самой Tilda. Цвета: белый, графит и золото; бежевый фон не используется.

## Особенности

- 5 фотографий размещены в коллаже; по нажатию можно посмотреть все 9 снимков с обучения.
- Портрет основателя — небольшое круглое фото возле его цитаты. Стаж «более 10 лет» указан по предоставленному тексту.
- Адаптивная композиция, поддержка клавиатуры в фотогалерее, без внешних библиотек.
- Блок не меняет существующие стили сайта Tilda, все селекторы ограничены `#elite-about-2026`.

Перед публикацией проверьте права на фотографии и корректность данных.
