# ELITE Dental Clinic — раздел «О клинике»

Готовая вставка для Tilda T123: **один блок** с текстом о клинике, фотоколлажем с обучения и цитатой основателя Адиля Ержановича с маленьким круглым портретом. Без карточек преимуществ, услуг, дополнительных CTA и бежевого фона.

## Файлы

- `about-block.html` — HTML/CSS/JS **только самого блока**. Вставлять в Tilda.
- `index.html` — демостраница с **схематичным первым экраном действующего сайта**, после которого размещён новый блок, а затем обозначен существующий раздел «Почему мы?». Окружающие блоки показаны только для понимания расположения и **не являются редизайном**.

## Установка на действующем сайте

1. Откройте главную страницу в Tilda.
2. Между **первым экраном с рекламными карточками** и разделом **«Почему мы?»** добавьте блок «Другое → T123 HTML-код».
3. Вставьте **полное содержимое `about-block.html`**, включая `<style>`, `<section>` и `<script>`.
4. Сохраните и **опубликуйте страницу**; в публичной версии проверьте все фотографии, мобильную адаптивность, шрифт и перелистывание.
5. Удалите предыдущую версию блока, если она уже добавлена в Tilda.

## Технические детали

- Встроенные изображения WebP через data URI: отдельной папки `assets` и ссылок на внешние картинки нет.
- Шрифты наследуются от основного шрифта Tilda; в тестовом standalone-предпросмотре используется системный Arial.
- Стили изолированы в селекторе `#elite-about-2026`, поэтому другие блоки сайта не меняются.
- Галерея: 5 фотографий в коллаже, ещё 4 доступны в просмотре; навигация стрелками и Esc.
- Исправлено: вместо HTML-кнопок `<button>` фотографии коллажа теперь размечены `<figure>` с `<img>`. Клик и клавиши Enter/пробел по фотографии по-прежнему открывают просмотр, но Tilda больше не получает нативные кнопки для коллажа.
- Уменьшен дублирующийся HTML-код изображений, чтобы снизить размер вставки.
- При публикации убедитесь, что разрешено использовать фотографии обучения и что описания сотрудников верны.

**Важно:** публикация файлов в GitHub или ссылка на демостраницу не добавляют блок на https://elitedentalclinic.kz/ автоматически. Это нужно сделать через редактор Tilda.
