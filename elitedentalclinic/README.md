# Elite Dental Clinic — блок «О клинике»

Адаптивный HTML/CSS/JS-блок для [elitedentalclinic.kz](https://elitedentalclinic.kz/), подготовленный под вставку в Tilda T123.

## Состав
- `about-block.html` — исходный код блока (вёрстка, стили и JavaScript). Пути к изображениям относительные: `./assets/*.webp`.
- Папка `assets/` — WebP-фотографии в полном комплекте, приложенном к ответу ChatGPT в архиве `elitedentalclinic-tilda.zip`.

## Быстрый импорт в Tilda
Для немедленной установки используйте файл **`tilda-embed-PORTABLE.html` из архива**, предоставленного в чате ChatGPT: в нём фотографии встроены в HTML, их не нужно дополнительно загружать.

Откройте Tilda → Библиотека блоков → Другое → T123 «HTML-код» → Контент → вставьте содержимое указанного файла → Опубликовать страницу.

**Важно:** `about-block.html` в GitHub — разработческий исходник со ссылками на локальную папку `assets/`. Пока WebP-фотографии из архива не загружены рядом с файлом, предпросмотр этой версии в GitHub будет без изображений. Полностью готовый к импорту файл — портативная версия из архива.

Включено: смысловой блок «О клинике», фото Адиля Ержановича, более 10 лет опыта, галерея 9 фотографий обучения, кнопка WhatsApp, адаптивная сетка и модальное увеличение фотографий.

## Контроль перед публикацией
1. Проверить, что фотографии участников разрешено размещать публично.
2. Убедиться, что в описании основателя корректны имя и стаж.
3. Учитывать, что на исходном фото основателя виден логотип другой стоматологической клиники; при необходимости заменить фото на фирменный портрет Elite Dental Clinic.

Стили изолированы по `#edc-about`. Не требуются внешние библиотеки.
