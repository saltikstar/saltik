# Elite Dental Clinic — блок «О клинике»

Только текст о клинике, фотоколлаж и цитата основателя Адиля Ержановича с круглым портретом. Белый фон, золотой акцент, шрифт наследуется от Tilda.

## Файлы

- `about-block.html` — вставка **только блока** в Tilda T123.
- `index.html` — предпросмотр расположения блока между первым экраном и «Почему мы?»; окружающий сайт на этой странице схематичный, не копия действующего.

## Установка

1. В Tilda добавьте блок «Другое → T123 (HTML-код)» после первого экрана и перед «Почему мы?».
2. **Полностью замените старый код** содержимым `about-block.html`.
3. Сохраните и опубликуйте страницу.

## Разметка фотографий

Внутри `.edc3-collage` находятся ровно пять **прямых дочерних элементов `<img>`** — без `<button>`, `<figure>`, `<a>` и любых обёрток. CSS Grid задаётся непосредственно классами изображений `.edc3-tile--1` … `.edc3-tile--5`. Нет JavaScript, диалога-галереи и обработчиков на фотографиях: это просто картинки.

WebP изображений встроен в атрибуты `src` через data URI, отдельная папка `assets/` не нужна. Фотография основателя остаётся круглой рядом с цитатой.
