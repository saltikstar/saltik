# Elite Dental Clinic — обновлённый блок «О клинике»

Версия 2: editorial-дизайн по новому направлению референсов для постепенного редизайна [elitedentalclinic.kz](https://elitedentalclinic.kz/).

## Файлы
- `about-block.html` — **готовый код для Tilda T123** (CSS + HTML + JS и 10 WebP-фотографий внутри файла).
- `index.html` — отдельная HTML-страница для просмотра макета (если настроен GitHub Pages).
- `DESIGN.md` — палитра, композиция и принципы для последующего обновления остальных секций.

## Установка в Tilda

1. Откройте [about-block.html](./about-block.html) → **Raw**, скачайте файл или скопируйте его содержимое.
2. На странице Tilda замените код старого блока T123 всем содержимым нового файла.
3. Сохраните и **опубликуйте** страницу; проверьте на смартфоне.
4. Все фотографии включены в HTML. Отдельный хостинг или папка assets не требуются.

## Содержимое
- «О клинике» — заголовок, описание, CTA с WhatsApp.
- «Основатель» — Адиль Ержанович, более 10 лет в стоматологии и цитата.
- «Развитие» — коллаж из 5 фотографий, просмотр всех 9 в галерее.

## Совместимость и ограничения
- Шрифт **наследуется от Tilda**, без внешних шрифтов.
- Стили изолированы в `#edc-about-v2`, не меняют другие блоки сайта.
- Фото основателя композиционно обрезано; сторонний логотип на одежде не показан.
- Перед публикацией согласовать публичное использование фотографий.
- Встраиваемые картинки увеличивают размер HTML; при полноценном редизайне лучше перейти на оптимизированные WebP/AVIF по CDN.
- Сам файл в GitHub — исходник. Он не появляется автоматически на действующем сайте, пока код не вставлен в T123.
