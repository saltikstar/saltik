# ELITE Dental Clinic — блок «О клинике» для Tilda

Готовый адаптивный блок: портрет основателя, текст о клинике и галерея 9 фотографий с обучения.

## Как установить

1. Откройте файл [about-block.html](./about-block.html) в GitHub и выберите **Raw/Download**, чтобы получить полный код.
2. В Tilda добавьте на нужную страницу **T123 — HTML-код**.
3. Вставьте **весь** код из `about-block.html` (от `<style>` до `</script>`), сохраните и опубликуйте страницу.
4. Удалите старый код блока, если он был добавлен ранее. Он не обновляется автоматически из GitHub.

## Исправления

- Все 10 изображений (портрет и 9 фото обучения) встроены прямо в HTML в WebP-формате. **Папка `assets/` не требуется**. Относительных путей больше нет.
- Убраны принудительные Arial и Georgia: типографика наследуется от настроенного в Tilda шрифта сайта.
- Блок ограничен собственным CSS-контейнером `#edc-about`, чтобы его стили не конфликтовали с основным сайтом.

## Примечания

- Размер HTML увеличен из-за встроенных изображений; на GitHub удобнее получать файл через Raw или Download.
- Если фотографии не видны в редакторе Tilda, проверьте **опубликованную** страницу.
- Перед публикацией стоит согласовать портрет: на форме виден логотип другой клиники.
- Проверьте согласие участников фото на публичное размещение.
