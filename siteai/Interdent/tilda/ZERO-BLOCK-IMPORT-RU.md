## 2. Как импортировать (каждый файл отдельно)

1. Добавьте **новый Zero Block**, откройте меню **«…» → «Импорт из HTML»**.
2. Выберите **только один файл** из папки `zero-blocks/`.
3. Нажмите «Подготовить к импорту».
4. Выберите **«Применить настройки к артборду»**, когда импортируете в отдельный пустой Zero Block.
5. Включите **«Уменьшить вложенность групп»**.
6. Проверьте настройки брейкпоинтов: **1200, 960, 640, 480 и 320 px** (или эквивалентные диапазоны Tilda). Просмотрите каждый.
7. Завершите импорт. В редакторе проверьте изображения и текст, затем настройте отдельные высоты артбордов — чтобы не обрезать длинные описания и не оставить пустое место.

**Важно:** импорт HTML преобразует CSS/HTML в элементы Zero Block, но не гарантирует, что `display:flex` автоматически станет нативным Tilda **Object Group Auto Layout**. После импорта сгруппируйте карточки/кнопки в Object-группы и включите **Auto Layout** в настройках группы.

Официальная документация: 
- https://help-ru.tilda.cc/zero/import-methods/html-file-import
- https://help-ru.tilda.cc/zero/auto-layout
- https://help-ru.tilda.cc/zero/advanced

## 3. Первый экран: фотография команды

В `01-hero-background.html` изображение задано как **background-image** отдельного контейнера `.it-photo`, а не `img` или `picture`. В CSS есть адаптивность, на мобильной ширине используется другое кадрирование/фото.

Если Tilda не импортирует CSS-фон: **не пытайтесь повторно импортировать файл**. Выделите соответствующую фигуру (Shape) справа или добавьте Shape в Zero Block → Background Image → загрузите фото:

- десктоп: https://saltik.sito.kz/siteai/Interdent/assets/team-hero.webp
- мобильный: https://saltik.sito.kz/siteai/Interdent/assets/team-clinic.webp
- резервные адреса: https://raw.githubusercontent.com/saltikstar/saltik/main/siteai/Interdent/assets/team-hero.webp и `.../team-clinic.webp`

Настройки: режим **Cover**, позиционирование **Center**, радиус карточки по дизайну. На десктопе — правая часть первого экрана на всю его высоту. На мобильном (320–639) — фото шириной экрана после шапки и перед заголовком, высота порядка 220 px, без растягивания лица.

**Нельзя гарантировать по коду, что Tilda автоматически сохранит CSS-фон.** Для фона артборда или Shape доступны отдельные настройки загрузки картинки в Zero Block.

## 4. Мобильная версия и Auto Layout

Файлы содержат CSS-медиа-запросы для 960, 640 и 480 px, а первый экран — для 760 px. Однако после преобразования в Zero Block каждый диапазон нужно проверить и при необходимости донастроить.

- 1200 и больше: карточки сеткой, первый экран в две зоны.
- 960–1199: уменьшение горизонтальных промежутков и переход некоторых карточек на две колонки.
- 640–959: компактный планшет, перенос карточек по строкам.
- 320–639: основной контент в одну колонку, исключение — если два изображения отзывов читаемы.
- 320–479: отзывы выводятся по одному, чтобы не уменьшать текст.
- Изображения документов/КТ/отзывов — **Contain**, без обрезки. Сервисные фотографии — **Cover**.
- Основной текст: десктоп от 18 px, мобильный от 14–15 px. Кликабельные зоны от 44 px.

Для кнопок и карточек: Group → Object → Auto Layout → Direction Horizontal/Vertical/Wrap, затем Gap, Padding и Hug/Fixed. Проверьте порядок чтения на мобильном, особенно у фото и текста.

## 5. Профили врачей (7 отдельных всплывающих окон)

Для нативного редактирования в Zero Block используйте облегчённые файлы **`popups-zero/doctor-*.html`**. Они содержат полностью раскрытые анкеты каждого врача и кнопку записи; без SVG и JavaScript. Подробная схема: **`popups-zero/README-RU.md`**. Исходные версии остаются в `popups/`.

В разделе `08-doctors.html` ссылки «Подробнее» ведут на `#doctor-abu`, `#doctor-maksat`, `#doctor-gaziza`, `#doctor-zhuldyz`, `#doctor-aliya`, `#doctor-akmaral`, `#doctor-indira`.

Для каждого профиля:
1. Создайте **отдельный пустой Zero Block** и импортируйте нужный `popups-zero/doctor-*.html` через меню Zero Block «… → Импорт из HTML» (не через Tiltify/Figma JSON).
2. Установите прозрачный фон артборда и проверьте Auto Layout / высоту длинного содержимого на мобильном.
3. Добавьте **отдельный модификатор T1093** (Popup: Zero Block в попапе).
4. В T1093 выберите реальный ID созданного Zero Block и укажите соответствующий хэш `#doctor-...`.
5. Проверьте открытие по «Подробнее», закрытие, прокрутку длинного текста и кнопку «Записаться».

Документация: https://help-ru.tilda.cc/zero

## 6. Отзывы

HTML-секция отзывов содержит 16 изображений и не зависит от JavaScript: каждое изображение ведёт на полную версию в новой вкладке. Это стабильный резерв для импортированной версии; для нативного lightbox/слайдера перенесите скриншоты в Tilda Gallery и настройте увеличение через её встроенные функции. Нельзя считать оригинальный JS-слайдер автоматически перенесённым.

## 7. Карта и документы

В Zero Block HTML импорт iframe может не превратиться в рабочий элемент. Поэтому в `11-contacts.html` карта заменена переходом в 2ГИС. Для **встраиваемой карты** используйте отдельный T123 с кодом из `t123-map.html`, не HTML-импорт Zero Block.

PDF-документы в `docs/` и все фотографии желательно загрузить в Tilda и заменить внешние адреса на её CDN после импорта. В разделе документов все внешние ссылки необходимо проверить вручную.

## 8. Перед публикацией

- Шрифты **Cormorant Garamond** и **Manrope** подключить в настройках сайта.
- Проверить фото команды в Zero Block на **320, 375, 480, 640, 960, 1200 и 1440 px**.
- Проверить все внешние адреса изображений и PDF, исчезнувшие изображения загрузить вручную.
- Проверить ссылки на WhatsApp, телефоны, цены, отзывы, попапы всех 7 врачей, 2ГИС.
- Проверить публикацию на реальном мобильном, отсутствие горизонтальной прокрутки и корректные высоты артбордов.
- Провести техническую проверку уже опубликованной страницы; импорт сам по себе не гарантирует готовность к публикации.

## Позиционирование

Факты и текст клиники перенесены из текущего проекта без изменения медицинских обещаний или добавления неподтверждённых отзывов. Этот комплект предназначен **для нативного редактирования блоков в Tilda**, а не для вставки всей страницы единым T123.
