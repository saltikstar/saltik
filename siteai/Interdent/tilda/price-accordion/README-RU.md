# Interdent Clinic — рабочий прайс-аккордеон для Tilda

Данные услуг, цены, категории и текст взяты из существующей секции прайса Interdent Clinic, без изменений. Восемь категорий, 58 строк услуг.

## Рекомендованный быстрый вариант (стабильно)

Откройте страницу Tilda → «Добавить блок» → Другое → **T123 (HTML-код)**. Скопируйте в него **всё содержимое файла price-ready-t123.html**. Опубликуйте страницу и проверьте аккордеон — скрипт входит в тот же HTML. Встроенный CSS имеет мобильную адаптацию; высота блока автоматически следует за содержимым.

## Если хотите сохранить редактируемый Zero Block из Tildify

1. Импортируйте **price-tildify.html** в пустой Zero Block (не весь сайт).
2. Убедитесь, что после импорта группы сохранили классы: общий контейнер `ic-price-accordion`, каждый пункт `ic-price-item`, заголовок `ic-price-header`, содержимое `ic-price-content`. Если классы потерялись, назначьте их соответствующим Object-группам вручную.
3. Для динамической высоты включите **Object Group → Auto Layout → Vertical** у контейнеров пунктов и общего списка. Изменения высоты должны влиять на последующие элементы, а не перекрывать их.
4. Сразу после Zero Block добавьте **T123** и вставьте полное содержимое `price-code-for-T123.html` — CSS + JavaScript. Только JS без CSS может потерять скрытие и поворот плюса, если классы после импорта не сохранились.
5. Опубликуйте страницу. Проверять работу T123 нужно на опубликованной странице, не только в редакторе Tilda.

⚠️ **Не подключайте одновременно встроенный Tildify Elements Accordion и данный JavaScript на одни и те же элементы.** Выберите либо свой JS + описанные классы, либо штатный Tildify Accordion со своими `tf_accordion-*` и конфигом.

## Что делает JS

При открытии одной категории закрывает остальные; изначально открыта «Диагностика». Повторный клик закрывает текущую категорию. Управление также доступно Enter/Пробелом. Не использует внешних библиотек. Работает с DOM после загрузки и при позднем появлении Zero Block. Не управляет физической высотой артборда Zero Block: для этого требуется Auto Layout.

Источник документации: https://tildify.ru/accordion и https://help-ru.tilda.cc/html

Если после импорта Tildify весь прайс преобразуется в статичные тексты и фигуры, **сам по себе JS не вернёт потерянную группировку**; первый вариант через T123 надёжнее.
