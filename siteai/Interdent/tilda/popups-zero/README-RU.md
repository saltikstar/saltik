# Interdent Clinic — 7 отдельных popup-профилей для Tilda Zero Block

## Что подготовлено

Каждый HTML-файл — самостоятельный **раскрытый профиль врача** (не карточка-превью).
Внутри: имя, специализация, опыт, подтверждённые описания направлений из существующего проекта, кнопка «Записаться» в WhatsApp с именем выбранного врача.

Никакого JavaScript, SVG и Figma-JSON. Внешние шрифты не загружаются кодом: подключите Manrope и Cormorant Garamond в настройках Tilda. Для показа окон используйте **штатный модификатор T1093**. Исходные профили сохранены в `../popups/`; основной блок карточек `../zero-blocks/08-doctors.html` не изменён.

## Настройка в Tilda

1. Оставьте основной раздел «Наши врачи» с 7 карточками на странице. У каждой карточки «Подробнее» проверьте ссылку из таблицы.
2. Создайте **первый отдельный пустой Zero Block** для Бурбаева Абу. В редакторе Zero Block: `… → Импорт из HTML`. Выберите `doctor-abu.html` или вставьте полный HTML-код из файла. Нажмите «Подготовить к импорту».
3. Выберите **«Применить настройки к артборду»** для пустого Zero Block, включите «Уменьшить вложенность групп», импортируйте. При необходимости выделите один элемент `.td-popup`, если предпросмотр предлагает импортировать больше содержимого.
4. Установите для артборда **прозрачный фон**. Карточка внутри имеет фон `#f7f3ed`, скругление и внутренние отступы. Не добавляйте собственный крестик поверх контента — крестик обеспечивает T1093.
5. Проверьте брейкпоинты в Zero Block. Текст должен помещаться, кнопку «Записаться» оставить доступной внизу. При необходимости объедините элементы в Object Group с Auto Layout (vertical, Hug). **Не ставьте одну фиксированную высоту всем врачам**: анкеты разной длины.
6. Добавьте из категории «Другое» блок **T1093 «Popup: Zero Block в попапе»**. В нём выберите только что созданный Zero Block (его реальный ID вида `rec...`) и задайте ссылку `#doctor-abu`.
7. Повторите шаги для остальных шести HTML-файлов: каждый новый Zero Block + отдельный T1093 с собственным хэшем. **Не используйте один и тот же ID Zero Block для разных врачей.**
8. Настройте затемнение фона, контрастный крестик закрытия и прокрутку. Опубликуйте страницу, проверьте все 7 «Подробнее», закрытие окна, прокрутку длинных профилей и кнопки WhatsApp на мобильном.

**Обратите внимание:** на этапе импорта HTML преобразуется в элементы Zero Block. Поведение CSS-групп, переносы строк и высоту необходимо проверить в самом редакторе. На узких экранах для длинных профилей при обрезании контента проверьте высоту артборда и настройки Overflow Y: Auto.

## Если у вас открыт Tiltify

Tiltify импортирует JSON из Figma, **не эти HTML-файлы**. Для этих профилей используйте встроенный импорт `… → Импорт из HTML` самого Zero Block. По официальной документации Tilda функция HTML-импорта может требовать включить в профиле опцию «Участвовать в тестировании новых функций».

## Почему не нужен JS

T1093 связывает Zero Block и кнопку по хэшу. Сами профили — статический редактируемый контент. Не переносите `<script>` исходного сайта и не вставляйте popup в T123: это другая схема, лишающая контент нативного редактирования в Zero Block.
