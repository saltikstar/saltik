# Импорт первого экрана Interdent в Tilda Zero Block

**Используйте файл `hero-zero-import.html`, а не `index.html` действующего сайта.**

В этом файле:
- Отсутствует тег `picture`, фото подключено обычным `img`.
- Все изображения имеют абсолютные HTTPS-адреса, а не `assets/...`.
- CSS встроен в HTML, JavaScript отсутствует.
- Разметка упрощена для Zero Block.
- Фото команды имеет собственную высоту и не зависит от отрицательного z-index.

## Порядок
1. Откройте Zero Block → меню «…» → «Импорт из HTML».
2. Загрузите `hero-zero-import.html` или вставьте его содержимое.
3. Выберите «Подготовить к импорту», затем «Применить настройки к артборду» и «Импортировать».
4. Включите «Уменьшить вложенность групп», если импорт добавляет лишние группы.
5. Проверьте, что фото отображается как отдельный Image-элемент, и настройте мобильные брейкпоинты.
6. Если изображение не появилось, добавьте его через Image → Upload URL: `https://raw.githubusercontent.com/saltikstar/saltik/main/siteai/Interdent/assets/team-hero.webp`.

Это подготовка **только первого экрана**. Импорт из HTML не выполняет JavaScript, поэтому интерактивы остальных секций необходимо переносить отдельно через T123. Документация: https://help-ru.tilda.cc/zero/import-methods/html-file-import

После импорта проверьте веб-шрифты Cormorant Garamond и Manrope в настройках Tilda. Перед публикацией убедитесь, что изображения загружены на Tilda (а не остаются внешними URL).
