# Interdent Clinic — сайт-концепция v3

Адаптивный одностраничный сайт стоматологии Interdent Clinic (Астана, ул. Кенесары, 52), переработанный по предоставленным референсам клиники «Элеоника».

## Посмотреть

- GitHub: `https://github.com/saltikstar/saltik/tree/main/siteai/Interdent`
- GitHub Pages (при настроенной публикации): `https://saltikstar.github.io/saltik/siteai/Interdent/`
- Для локального просмотра откройте через статический сервер, например `python -m http.server 8000` из папки `Interdent`.

## Что сделано

- **Первый экран:** единый фотореалистичный визуал, закруглённый контейнер, белая навигационная капсула поверх фото, брендовый заголовок, две кнопки, три факта и нижняя полоска сервисной информации.
- **Услуги:** 6 фото-карточек и ещё 3 направления, переходы к прайсу.
- **Консультация/диагностика:** двухколоночный блок в духе референса, с реальной ценой консультации **5 000 ₸** по полученному прайсу; не заявляем «бесплатно» или «20 минут».
- **Цены:** 8 раскрывающихся групп и позиции из оригинального ТЗ.
- **Врачи:** 7 профилей из ТЗ, 5 оригинальных портретов клиента и 2 прозрачные заглушки.
- **Отзывы:** 8 исходных скриншотов от клиента, просмотр в модальном окне.
- **Документы:** PDF лицензии, приложения, справки о регистрации на русском и казахском, документальные миниатюры.
- **Контакты:** режим работы, телефоны, маршрут 2ГИС и WhatsApp.

## Визуальные исходники и достоверность

- `assets/mark.webp`, оригинальные портреты и `review-*.webp` — из материалов заказчика.
- `assets/hero-treatment*.webp`, `*scene.webp`, `diagnostic-scene.webp`, `microscope-scene.webp` — **концептуальные визуализации**, составленные из специально сгенерированных изображений. Они не являются фотографиями реальной клиники или её пациентов.
- Два изображения документа (`license-thumb.webp`, `registration-thumb.webp`) созданы из предоставленных PDF, не генерация.
- Позиционирование «с 2016 года» указано в предоставленном скриншоте Instagram клиники; до публичного запуска требуется согласование.
- «Kaspi Red / рассрочка / ЕНПФ» взято из Instagram-профиля, конкретные условия необходимо подтвердить у клиники.

## Технологии

Чистые HTML + CSS + JS, без сборщика и сторонних UI-библиотек. Mobile-first адаптация, семантические разделы, отслеживаемые клики по WhatsApp/телефону, `prefers-reduced-motion`, работающий мобильный dropdown, модальные окна с клавиатурным управлением.

Типографика: основной текст **18px на десктопе** и **15px на мобильных**. Подписи и служебные элементы могут быть меньше.

## Проверка

Chromium — 1440×900, 820×1180, 390×844; нет горизонтального переполнения, отображаются 6 фото-карточек, 7 врачей, 8 групп прайса, 8 отзывов; рабочие меню, раскрытие цен, просмотр отзывов. На реальном домене проверить навигацию, ссылки, аналитику, работу мобильных устройств и performance.

## До окончательного запуска

Получить настоящие интерьерные фото / фото процедур, два недостающих портрета, согласовать историю клиники, условия оплаты, цены, юридические тексты и поставить актуальные коды аналитики. Изображения-визуализации заменить на реальные фото по мере получения.
