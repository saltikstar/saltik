# Interdent Clinic — концепция сайта (v2)

Адаптивная статическая одностраничная концепция для стоматологии Interdent Clinic, Астана.

## Просмотр

Открыть `index.html` локально через статический веб-сервер (например, `python -m http.server 8000`) или GitHub Pages по адресу `/saltik/siteai/Interdent/` при включённой публикации Pages.

## Файлы

- `index.html` — семантическая разметка, тексты, услуги, прайс, документы и SEO.
- `styles.css` — полностью новая редакционная дизайн-система, адаптив.
- `script.js` — мобильное меню, цены (native details), отзывы, модальные окна, клики WhatsApp.
- `assets/` — исходный бренд и портреты клиента, оригинальные скриншоты отзывов и оптимизированные композиции из реальных фото.
- `docs/` — предоставленные юридические PDF.
- `DESIGN.md` — дизайнерские решения и список ограничений.

## Что изменилось в v2

Убраны крупные клише AI-дизайна: плавающие карточки, дуги и декоративные звёздочки, необоснованно сложный первый экран, однотипные цветные сервисные плитки и фальшивая иллюстрация интерьера. Первый экран теперь цельный фото-блок, услуги получили три редакционных фото-карточки, заголовки и сетка приблизились к предоставленному референсу.

## Проверки

- Основной текст: от 18 px на десктопе, от 15 px на телефоне.
- 1 × H1, адаптивные секции, без горизонтального переполнения.
- Проверка в Chromium на desktop/tablet/mobile; меню, прайс, отзывы, модальные окна работают.
- Сайт не подключён к CRM; CTA открывают WhatsApp.
- События отправляются в подключаемый позже `dataLayer`/`gtag`/`fbq`.

## Перед запуском

Получить реальные фото кабинетов и два оставшихся портрета, подтвердить цены и медицинские формулировки; подключить аналитику и проверить GitHub Pages/домен.
