# Interdent Clinic — дизайн-концепция сайта

Одностраничная концепция для Interdent Clinic, Астана, по ТЗ заказчика и референсу. Без сборки: обычные HTML, CSS, JavaScript, относительные пути к локальным изображениям.

## Как открыть

Откройте `index.html` в браузере или запустите простой сервер в каталоге проекта: `python3 -m http.server 8080`. При размещении в GitHub Pages может открываться по пути `/saltik/siteai/Interdent/`, если GitHub Pages опубликован из соответствующей ветки и каталога.

## Что реализовано

- Тёплая светлая палитра с коричневыми и золотыми акцентами из фирменного логотипа.
- Основные тексты **18 px на десктопе** и **15 px на мобильных** (не ниже 14 px для контента). Заголовки масштабируются.
- Адаптивная навигация, все основные секции, 8 направлений услуг, подробный аккордеон цен из ТЗ.
- Семь карточек врачей, пять оригинальных портретов; у двух карточек нейтральные заглушки вместо выдуманных фото.
- Восемь оригинальных скриншотов отзывов с просмотром в модальном окне.
- Контакты, телефон, WhatsApp с шаблоном сообщения, ссылки на Instagram и 2GIS.
- Базовая SEO-разметка, структурированные данные Dentist, клавиатурная навигация, `prefers-reduced-motion`.
- События `whatsapp_click` и `phone_click` для GA4/GTM и Meta при подключении реальных кодов рекламного специалиста.

## Перед публичным запуском

1. Согласовать утверждение о «10 годах работы»: в концепции оно сознательно не опубликовано, потому что приложенные юридические документы не подтверждают дату начала работы бренда.
2. Получить настоящие фотографии интерьера и командное фото, заменить оригинальной галереей иллюстративный блок кабинета. Иллюстрация **не является фотографией клиники**.
3. Получить и разместить полный PDF-прайс. Сейчас кнопка честно ведёт на уточнение в WhatsApp.
4. Добавить портреты Исмаиловой Жулдыз и Абсаттаровой Индиры и проверить корректность соотнесения остальных портретов с ФИО.
5. Проверить актуальность лицензии и приложений: в разделе сведений о лицензии доступны исходные PDF-сканы и справки (RU / KK), переданные заказчиком.
6. Подключить коды GA4 / Google Ads / Meta Pixel после передачи специалистом. Реальные события проверить в отладчиках аналитики и браузере.
7. Утвердить тексты и прайс-лист, проверить сайт на устройствах и Lighthouse, подготовить домен и SSL.

## Источники

- `ТЗ на сайт Interdent Clinic.docx`, материалы и реальные фото/отзывы, переданные заказчиком в чате.
- Лицензия №23009225 от 18.04.2023 и приложение №007 от 31.01.2024.
- База стандартов WEB STUDIO.

Данные пациентов не запрашиваются: единственное действие записи — открытие WhatsApp. Скриншоты отзывов предоставлены заказчиком. Не используйте фотографии врачей отдельно от одобренного контекста клиники.
