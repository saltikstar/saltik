# Elite Dental Clinic — гнатология / первый экран

Отдельный проект внутри `siteai`. Главный сайт в корне `siteai` — другой клиент, **Smile Studio Care**; его файлы не менялись.

## Просмотр

- Страница: https://raw.githack.com/saltikstar/saltik/main/siteai/elitedentalclinic/index.html
- Альтернативный URL на хостинге проекта (если настроена синхронизация каталога): https://saltik.sito.kz/siteai/elitedentalclinic/

## Состав

- `index.html` — полноценная HTML-страница первого экрана.
- `hero-block.html` — тот же первый экран без внешнего HTML, для вставки в Tilda T123.

## Содержание

Атаманов Азамат Болатбекович — врач-гнатолог, Усть-Каменогорск. Белый фон, графитовый текст, акцент золотого цвета, кнопка записи через WhatsApp клиники. **Профессиональный портрет пока не предоставлен**: на его месте нейтральная заглушка с буквами «АБ».

Изображения врача, гарантии, стаж и достижения не выдуманы. Для замены заглушки необходимо загрузить реальный портрет.
