# Elite Dental Clinic — первый экран, преимущества и услуги

Демонстрационная страница: `siteai/elitedentalclinic/index.html` (сейчас: первый экран гнатолога + преимущества + услуги). В исходные файлы другого клиента в `siteai/index.html` изменений не внесено.

## Ссылки

- Предпросмотр: https://raw.githack.com/saltikstar/saltik/main/siteai/elitedentalclinic/index.html
- Репозиторий: https://github.com/saltikstar/saltik/tree/main/siteai/elitedentalclinic

## Файлы

- `index.html` — единая страница для просмотра.
- `hero-block.html` — первый экран, отдельно для Tilda T123.
- `features-services.html` — разделы «Почему мы?» и «Наши услуги», отдельно для Tilda T123.

## Состав обновления

Сохранены пять преимуществ с существующего сайта и пять направлений стоматологии. Описания услуг переработаны по материалам https://elitedentalclinic.kz/ для показа прямо в карточках: гнатология, терапия, ортодонтия, хирургия, пародонтология. У каждой услуги своя ссылка на запись через WhatsApp клиники, без попапов. Общие стили: белый/светло-серый фон, графитовый текст, золотой акцент, наследование шрифта Tilda; адаптивные сетки, scoped CSS.

**Важно:** профессиональное фото Атаманова Азамата Болатбековича ещё не предоставлено: первый экран пока содержит заглушку «АБ». Не утверждаем неподтверждённые результаты и гарантии лечения.

## Вставка в Tilda

1. Для первого экрана используйте отдельный блок T123 с кодом из `hero-block.html`.
2. Сразу следом добавьте T123 с кодом из `features-services.html`.
3. Опубликуйте страницу, проверьте запись через WhatsApp и отображение блоков на телефоне.
4. Старые разделы «Почему мы?» и «Услуги» на странице Tilda нужно скрыть/удалить, чтобы не было дублей.

GitHub-демо не синхронизирует содержимое T123 автоматически.
