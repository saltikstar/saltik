# Elite Dental Clinic — комплект Tilda v44

Актуальный источник: ../index.html. Старые самостоятельные HTML-файлы остаются историческими и не должны смешиваться с этим комплектом.

## Вариант A — один T123 (рекомендуемый первый тест)
Вставить весь `page-t123.html` в один блок T123 на отдельной тестовой странице. Убрать дублирующие нативные блоки только на тестовой копии. Фрагмент содержит актуальные стили, разметку и скрипты; нет внешних тегов html/head/body. Глобальные правила body и scroll-behavior не переносились. Проверить совместимость с CSS Tilda, sticky-шапку (родительские обертки Tilda могут влиять на position:sticky), модальные окна и шрифт Tilda Sans.

## SEO
Настроить Title/Description в настройках страницы Tilda. `head-reference.html` — справочник метаданных и JSON-LD; не вставлять целиком без проверки дублей с метаданными, которые формирует Tilda. Canonical проверить по окончательному домену. Тестовую страницу закрыть от индексации в Tilda. На боевой странице после согласования снять ограничение.

## Изображения
25 локальных WebP-ресурсов доступны по ссылкам на закрепленную версию GitHub через raw.githack.com. Это временный источник для тестирования, не рекомендуемый production CDN. Перед публикацией загрузить их в Tilda или на утвержденный постоянный HTTPS-хостинг и заменить префикс URL во всех местах. Внешние Tilda CDN URL сохранены. Не менять object-fit, пропорции или кадрирование. Медицинские иллюстрации не являются доказательством результата лечения.
