# ORTHODONT.KZ — сайт клиники

Проект находится в `siteai/orthodont`.

- [index.html](./index.html) — рабочий одностраничный сайт, включая встроенные оптимизированные фотографии услуг и врачей, 10 клинических случаев, сертификаты и страницы лицензии.
- Сайт можно открыть как самостоятельный HTML-документ. Для последующей миграции на Tilda рекомендуем вынести изображения из data URI в медиатеку Tilda.

## Проверки перед публикацией
- Подтвердить согласие пациентов на публичное размещение клинических фотографий.
- Подтвердить соответствие фотографий врачей и имён (порядок задан по присланным материалам).
- Проверить актуальность контактных номеров, адресов, часов работы и условий рассрочки.
- Фотографии с брекетами на этапе лечения не обозначены итоговым результатом.

Исходные изображения и оригинальная PDF-лицензия сохранены в отдельном архиве проекта, доступном в рабочей переписке.
