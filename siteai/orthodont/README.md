# ORTHODONT.KZ — сайт клиники

Исходники одностраничного сайта находятся в `siteai/orthodont`.

- `index.html` — самостоятельный HTML-превью сайта. 
- `assets/media/` — 47 локальных оптимизированных изображений: врачи, работы, сертификаты и скриншоты отзывов из 2ГИС. Пути относительны `index.html`.
- Все изображения, в том числе до/после и документы, должны пройти финальное согласование с клиникой перед публикацией.
- Видеоотзывы: в `index.html` подготовлена адаптивная карусель, которая автоматически включается, когда MP4 доступны по путям ниже. Пока файлов нет, блок скрыт, чтобы не показывать нерабочие плееры.

## Видеофайлы, которые осталось загрузить

Поместить **три оригинальных MP4** в каталог `siteai/orthodont/assets/`:
- `review-01.mp4` — 4 168 782 байта
- `review-02.mp4` — 17 671 612 байт
- `review-03.mp4` — 7 592 737 байт

После появления файлов видеокарусель на сайте заработает без правок HTML. Скриншоты фотоотзывов уже находятся в `assets/reviews/` и подключены.

## Перенос на Tilda

- «Наши работы»: использовать стандартный блок галереи/карусели Tilda (например, GL10N); только фото, без подписей.
- «Сертификаты»: аналогичная фотокарусель Tilda без подписей, с открытием полноразмерного изображения.
- «Отзывы»: видеоотзывы и карусель скриншотов отзывов из 2ГИС; проверить законность публикации и персональные данные.
- HTML-превью само по себе не создаёт блоки в аккаунте Tilda.

## Проверить перед публичным запуском

Согласие пациентов на клинические фото; соответствие имён и фотографий врачей; номера, адреса, часы работы, условия рассрочки; лицензии и сертификаты. Фотографии промежуточных этапов лечения не следует обозначать финальным результатом.
