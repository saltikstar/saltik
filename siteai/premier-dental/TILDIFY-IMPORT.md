# Перенос Premier Dental Clinic через Tildify в Tilda

**Исходный сайт:** https://saltik.sito.kz/siteai/premier-dental/  
**Репозиторий:** https://github.com/saltikstar/saltik/tree/main/siteai/premier-dental  
**Рекомендуемый способ:** Tildify → Vibe Block Code → Tilda Vibe Block.  
**Технологии:** HTML + CSS Flexbox + минимальный Vanilla JS, без сборки и внешних JS-библиотек.

## 1. Захват исходного сайта

1. Откройте исходный сайт в Chrome/Chromium и проверьте, что все изображения полностью загрузились.
2. Нажмите значок **Tildify** в браузере.
3. Выберите **Vibe Block Code**, затем «Вся страница» или одну смысловую секцию. Для редакторской гибкости предпочтительнее переносить секциями: шапка, герой, услуги, акции, врачи, работы, документы, отзывы, FAQ, призыв, контакты, подвал.
4. Выберите **HTML + CSS + JS** для блоков с меню или интерактивом «До / После». Для прочих блоков можно использовать HTML + CSS.
5. Если копируете всю страницу сразу, проверьте лимит Vibe Block **150 000 байт**. Исходный HTML значительно меньше этого лимита, но результат захвата может быть объёмнее из-за преобразований расширения.

## 2. Вставка в Tilda

1. Добавьте **Vibe Block** на страницу Tilda, откройте его редактор кода.
2. Вставьте сгенерированный Tildify код из буфера.
3. Сохраните и проверьте отображение на компьютере и телефоне.
4. Для независимого редактирования отдельных блоков удобно переносить одну смысловую секцию в один Vibe Block.

> Если используете **Zero Block → Импорт из HTML**, учтите, что в этом режиме JavaScript не поддерживается; для меню и слайдеров нужен отдельный T123 или реализация штатными элементами Tilda. Поэтому для сохранения интерфейса предпочтителен Vibe Block.

## 3. Перенос изображений в Tilda CDN — обязательно

При первоначальной вставке Tildify может оставить изображения загружаться с домена исходного сайта. **Не ограничивайтесь тем, что фотографии уже видны на странице.**

1. В редакторе **Vibe Block** нажмите кнопку Tildify **«Загрузить все изображения»**.
2. Дождитесь завершения операции и убедитесь, что в коде/панели содержимого ссылки изменились с \`saltik.sito.kz/siteai/premier-dental/assets/...\` на адреса хранилища **Tilda CDN**.
3. Проверьте **все** изображения: главный экран, четыре карточки врачей, фотографии в услугах, галерею до/после, иллюстрацию блока отзывов и логотип.
4. Если SVG-логотип не перенёсся общей командой, выберите его и используйте отдельную загрузку изображения в Tilda.
5. Откройте опубликованную страницу в режиме инкогнито: фотографии должны загружаться без авторизации на исходном сайте.

Исходный сайт содержит **отдельные \`<img src="https://…">\`**, без base64 и CSS-спрайтов. Иконки Instagram и WhatsApp — **inline SVG**, их не требуется переносить как отдельные файлы.

## 4. Проверка Flexbox

- Основные контейнеры имеют \`display:flex\`, \`flex-wrap\`, \`flex-basis\`, \`gap\` и соответствующие настройки на мобильных экранах.
- Нет CSS Grid.
- После импорта проверьте переносы заголовков, ширину услуг и врачей, мобильное меню и отсутствие горизонтального скролла.
- Если Tildify поменяет макет какого-то блока, выделите контейнер и выберите **«Изменить макет» → Flex**.

## 5. Кнопки, социальные сети и карта

- Все внешние веб-ссылки заранее имеют \`target="_blank"\` и \`rel="noopener noreferrer"\`.
- WhatsApp: \`https://wa.me/77005551678?text=...\` — сообщение закодировано в самой ссылке; JavaScript не требуется.
- Instagram: \`https://www.instagram.com/premier_dental.cl/\`.
- 2GIS: \`https://2gis.kz/astana/geo/70000001018116030\`.
- Телефон: \`tel:+77005551678\` (открывается стандартный набор номера, а не новая вкладка).
- Якоря сайта: открываются внутри страницы. Если переносите секциями, убедитесь, что сохранены ID секций.
- Карта 2GIS использует iframe. Если Tilda удалит iframe или встроенная карта не загрузится, добавьте **HTML-блок T123** и перенесите туда iframe из исходного раздела «Как нас найти».
- Иконки Instagram и WhatsApp — узнаваемые векторные SVG из [Simple Icons](https://github.com/simple-icons/simple-icons), вставленные inline; зависимостей от FontAwesome и внешних иконочных шрифтов нет.

## 6. Контроль перед публикацией

- Десктоп 1440px / 1280px, планшет 768px, мобильные 390px / 360px.
- Базовый текст: **18px на десктопе** и **14px на мобильном**.
- WhatsApp с текстом обращения: кнопки шапки, услуг, акций, врачей, CTA и плавающая кнопка.
- Instagram и 2GIS в новой вкладке.
- Аккордеон FAQ открывается/закрывается.
- Ползунок галереи до/после меняет видимую границу.
- Карта 2GIS отображается и позволяет открыть маршрут.
- Убедитесь, что картинки обслуживаются Tilda CDN, а не старым доменом.
- Проверьте, что URL якорей, меню, скругления, изображения и шрифты сохранились.
- В настройках сайта Tilda установите **Manrope** как основной шрифт, если он не перенесся.
- Проверьте конфигурацию SEO Title / Description, favicon, analytics и отсутствие индексируемой дублирующей страницы, если меняется основной домен.

## Важные ограничения контента

Реальные фотографии врачей, лицензия и сертификаты требуют предоставления клиникой. Существующие демонстрационные фото используются только для макета и не должны выдаваться за реальные фотографии сотрудников.
