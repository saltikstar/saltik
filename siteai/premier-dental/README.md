# Premier Dental Clinic — сайт

Одностраничный адаптивный сайт по ТЗ для стоматологической клиники Premier Dental Clinic (Астана).

## Запуск
Откройте `index.html` локально или опубликуйте каталог `siteai/premier-dental` как статический сайт. Сборка и сторонние JavaScript-библиотеки не требуются.

## Палитра
Акцентный синий `#1455A4`, светлый фон, тёмная типографика. Композиция вдохновлена согласованным референсом, не копирует его.

## Изображения
В `index.html` предусмотрены файлы:
- `assets/implant-izen-before.jpg`
- `assets/implant-izen-after.jpg`
- `assets/restoration-before.jpg`
- `assets/restoration-after.jpg`
- `assets/caries-before.jpg`
- `assets/caries-after.jpg`

Они подготовлены из фотографий, предоставленных заказчиком. Фото и логотип собраны также в отдельном пакете исходных изображений, передаваемом в чате. **Бинарные изображения пока не загружены в GitHub через доступный коннектор; их требуется добавить в эту папку**. До добавления фото галерея показывает честные заглушки. Генерированные иллюстрации не представляют реальных сотрудников или интерьер клиники.
