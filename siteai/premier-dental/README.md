# Premier Dental Clinic — сайт

Адаптивный одностраничный сайт стоматологической клиники в Астане, реализованный по согласованному ТЗ и визуальному референсу.

## Открыть сайт

- Путь в репозитории: `siteai/premier-dental/index.html`
- Предполагаемый публичный адрес: https://saltik.sito.kz/siteai/premier-dental/
- Сайт статический (HTML + CSS + JavaScript), сборка не требуется.

## Изображения

- `assets/logo.svg` — векторная версия исходного логотипа, подготовленная по предоставленному заказчиком изображению.
- `assets/photo-sprite.webp` — единый оптимизированный файл с демонстрационными изображениями клиники и фрагментами **оригинальных клинических фотографий**, предоставленных заказчиком. Для экономии трафика кадры доступны через CSS-классы atlas.
- Врач на первом экране и изображения, используемые для иллюстрации работы специалистов, **сгенерированы**. Они не подтверждают личности сотрудников или реальный интерьер.
- Галерея «До / После» использует изображения из предоставленных клиентом клинических материалов.

## Функции

Якорное меню, мобильное меню, WhatsApp со стартовым текстом заявки, кликабельный телефон, переключатели сравнения клинических работ, FAQ-аккордеон, 2GIS и Instagram, адаптивная сетка.

## Что требуется до окончательного запуска

1. Заменить демонстрационные фотографии на подтверждённые снимки реальных врачей и клиники.
2. Добавить подлинные сканы медицинской лицензии и сертификатов с возможностью полноэкранного просмотра. Текущие графические элементы в блоке документов **не являются сканами документов**.
3. Проверить актуальность цен и акций и рейтинг 5,0 в 2GIS.
4. Проверить работу WhatsApp, телефона, внешних ссылок, карты и верстку на реальных мобильных устройствах.
5. Согласовать публикацию реальных клинических фотографий с клиникой, включая надлежащие согласия.

Неподтверждённые сведения о лицензии, образовании и опыте врачей не добавлены.
