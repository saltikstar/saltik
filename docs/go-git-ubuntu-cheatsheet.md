# Шпаргалка новичка: Ubuntu + Git + Go

Для самостоятельной подготовки к Tomorrow School / Piscine Go. Здесь не только команды, но и **зачем они нужны, куда их вводить и что получится**.

> **Важно об экзаменах:** использовать эту памятку во время Checkpoint можно **только если правила экзамена разрешают справочные материалы**. Если запрещены внешние источники и файлы — оставь памятку для подготовки, не открывай её во время экзамена.

## 0. Не путай три разных инструмента

| Инструмент | Для чего | Где писать |
|---|---|---|
| **Ubuntu / Bash** | Переходить по папкам, создавать файлы, запускать команды | Терминал Ubuntu в VS Code |
| **Git** | Запоминать версии файлов и отправлять их в удалённый репозиторий | Терминал Ubuntu |
| **Go** | Писать программы, функции, условия, циклы | Код в файлах `.go`; команды `go ...` — в терминале |

**Не вставляй `package main` в терминал.** Код Go пишется в файле `main.go`. А `go run main.go` — команда для терминала.

### `curl` и `jq` (знакомые по заданиям Shell)

```bash
curl -s https://example.com/data.json   # скачать текст JSON (пример адреса)
```

`curl` получает данные по HTTP, а `jq` извлекает поля JSON:


## 2. Git: сохранить и отправить работу

**Git** — история изменений. **GitHub или школьный Git-сервер** — место, куда отправляешь историю.

Обычная последовательность:

```bash
cd ~/piscinego             # зайти в школьный репозиторий
git status                 # проверить изменения
git add pointone.go        # подготовить конкретный файл
git commit -m "Add PointOne" # сохранить снимок в истории Git
git push origin main       # отправить коммит на сервер
```

Не обязательно выполнять `git add .`: он добавит **все** изменения, в том числе случайные. Сначала посмотри `git status`.

| Команда | Назначение |
|---|---|
| `git status` | Что изменено, подготовлено и не отслеживается |
| `git add file.go` | Добавить конкретный файл к следующему коммиту |
| `git add .` | Добавить изменения в текущей папке и вложенных (проверяй!) |
| `git commit -m "Сообщение"` | Создать коммит из подготовленных изменений |
| `git push origin main` | Отправить локальные коммиты на сервер |
| `git pull --rebase origin main` | Забрать удалённые коммиты и перенести поверх них свои (обычно при чистой рабочей папке) |
| `git log --oneline -5` | Последние 5 коммитов |
| `git diff` | Изменения в отслеживаемых файлах, ещё не добавленные в индекс |
| `git diff --staged` | Изменения, уже подготовленные к коммиту |
| `git branch` | Показать локальные ветки |
| `git remote -v` | Посмотреть адреса удалённых репозиториев |
| `git clone URL` | Скачать копию удалённого репозитория |
| `git init` | Создать новый локальный Git-репозиторий в текущей папке |
| `git switch ИМЯ` | Перейти на существующую ветку |
| `git restore --staged ФАЙЛ` | Убрать файл из подготовленного коммита, не удаляя его содержимое |

### Почему `nothing to commit`?

Git не видит новых подготовленных изменений. Может быть, ты не сохранила файл через `Ctrl + S`, изменила не ту копию проекта или файл не отличается от коммита.

Проверь:

```bash
pwd
git status
git diff -- pointone.go
```

### Почему `push rejected (fetch first)`?

На сервере появились коммиты, которых нет локально. При **чистой рабочей папке** обычно помогает:

```bash
git pull --rebase origin main
git push origin main
```

Если есть несохранённые изменения или конфликт, **не запускай команды наугад**: сначала `git status`. Не используй `git push --force` для учебного репозитория.

### Для собственной шпаргалки — отдельный репозиторий

Не клади личную шпаргалку в школьный `piscinego`: дополнительные файлы могут мешать проверке. Создай **отдельный** репозиторий на GitHub, например `go-notes`, и загрузи туда этот Markdown-файл через **Add file → Upload files → Commit changes**. Если памятка только для тебя, сделай репозиторий приватным.

## 3. Go: проверить, запустить, привести код в порядок

| Команда в терминале | Значение |
|---|---|
| `go version` | Показать версию установленного Go |
| `go run main.go` | Собрать и запустить конкретную программу |
| `go run .` | Собрать и запустить пакет в текущей папке (нужен подходящий проект с `package main`) |
| `go build` | Собрать проект без немедленного запуска |
| `gofmt -w main.go` | Автоматически форматировать и сохранить файл |
| `gofmt -w .` | Форматировать Go-файлы текущего пакета (в подходящем каталоге) |
| `go test ./...` | Запустить тесты во всех пакетах модуля |
| `go mod init example.com/myproject` | Создать `go.mod` для нового модуля |
| `go get github.com/01-edu/z01` | Добавить зависимость `z01` в **проект с `go.mod`** |

Для практики:

```bash
cd ~/go-practice
pwd
ls
go run main.go
```

Если выводится `8` — программа успешно отработала, например сложила `5 + 3`.

Для школьного задания сначала **проверь требуемое имя файла и пакет**. Если задание требует `package piscine`, такой файл сам по себе через `go run pointone.go` не запускается: у него нет точки входа `main()`.

### Как выглядит запускаемая программа

Файл `main.go`:

```go
package main

import "fmt"

func main() {
    a := 5
    b := 3
    fmt.Println(a + b)
}
```

Вывод: `8`.

- `package main` — специальный пакет запускаемой программы.
- `import "fmt"` — подключаем готовый пакет вывода.
- `func main()` — функция, с которой стартует программа.
- `{ ... }` — тело функции.
- `fmt.Println` — вывести значение и перейти на новую строку.

Школьная функция, например:

```go
package piscine

func Double(n int) int {
    return n * 2
}
```

`piscine` — название обычного пакета. `main()` там не нужна: его функции вызывает другой код.

### `go.mod` — что это

Пример:

```text
module piscine

go 1.26
```

Файл `go.mod` сообщает Go название модуля и версию языка, используемую проектом. Обычно он лежит **в корне модуля**. Не создавай по отдельному `go.mod` на каждую учебную функцию без требования задания.

## 4. Go: синтаксис и значения

### Типы данных

| Тип | Что хранит | Пример |
|---|---|---|
| `int` | Целое число | `10`, `-3`, `0` |
| `string` | Строка | `"Hello"` |
| `bool` | Истина/ложь | `true`, `false` |
| `rune` | Unicode-символ (код символа) | `'A'`, `'Я'` |
| `[]int` | Срез целых чисел | `[]int{5, 3, 7}` |
| `*int` | Указатель на целое число | `&a` |

```go
name := "Saltanat"   // новая переменная
age := 35
age = age + 1     // обновить существующую
age++             // прибавить 1
age += 5          // прибавить 5
age -= 2          // вычесть 2
age *= 3          // умножить на 3
age /= 2          // целочисленное деление при типе int
```

`:=` **создаёт** новую переменную внутри функции; `=` **присваивает** значение существующей.

`//` — комментарий до конца строки; он не выполняется.

### Арифметические операции

| Запись | Что означает | Пример |
|---|---|---|
| `+` | Сложение | `4 + 2` → `6` |
| `-` | Вычитание | `4 - 2` → `2` |
| `*` | Умножение | `4 * 2` → `8` |
| `/` | Деление | `13 / 2` → `6` для `int` |
| `%` | Остаток от деления | `13 % 2` → `1` |
| `++` | Увеличить на 1 | `i++` |
| `--` | Уменьшить на 1 | `i--` |
| `+=` | Прибавить и сохранить | `sum += i` |

`=` — присваивание, `==` — сравнение!

### Сравнения и логика

| Запись | Значение |
|---|---|
| `==` | Равно |
| `!=` | Не равно |
| `>` / `<` | Больше / меньше |
| `>=` / `<=` | Больше или равно / меньше или равно |
| `&&` | И: выполняются оба условия |
| `||` | ИЛИ: достаточно одного условия |
| `!` | НЕ: меняет `true` на `false` |

**Пример:** от 10 до 20 включительно:

```go
n >= 10 && n <= 20
```

**Пример:** число чётное:

```go
n % 2 == 0
```

**Пример:** число нечётное:

```go
n % 2 != 0
```

### `if`, `else if`, `else`

```go
func Check(n int) string {
    if n > 0 {
        return "Положительное"
    } else if n < 0 {
        return "Отрицательное"
    } else {
        return "Ноль"
    }
}
```

В Go `else` пишется **на той же строке, что и закрывающая `}`** предыдущего блока: `} else {`.

### Функции и `return`

```go
func Add(a int, b int) int {
    return a + b
}
```

- `func` — объявляем функцию.
- `Add` — имя функции.
- `a int, b int` — параметры и их типы.
- Последний `int` — тип возвращаемого результата.
- `return` — вернуть результат **и завершить функцию**.

Функция, которая ничего не возвращает:

```go
func SetToOne(n *int) {
    *n = 1
}
```

### Вывод на экран: `fmt`

```go
fmt.Print("Привет")             // без автоматического переноса
fmt.Println("Привет", 5)       // с пробелом между аргументами и переносом
fmt.Printf("Число: %d\n", 5)  // форматированный вывод
fmt.Printf("Буква: %c\n", 'A')
fmt.Printf("Текст: %s\n", "Go")
```

| Обозначение | Значение |
|---|---|
| `%d` | Целое число |
| `%c` | Один символ |
| `%s` | Строка |
| `%t` | Логическое значение `true/false` |
| `%v` | Значение в стандартном виде |
| `\n` | Переход на новую строку |

`"Hello"` — строка; `'H'` — один символ (`rune`).

## 5. Циклы `for`: три основных варианта

### А. Повторить заданное число раз

```go
for i := 0; i < 3; i++ {
    fmt.Print("*")
}
```

Результат: `***`.

- `i := 0` — начальное значение (выполняется один раз).
- `i < 3` — пока верно, продолжаем.
- `i++` — после каждого повторения увеличиваем на 1.

### Б. Накопить сумму

```go
sum := 0
for i := 1; i <= 4; i++ {
    sum += i
}
fmt.Println(sum) // 10: 1 + 2 + 3 + 4
```

### В. Перебрать элементы через `range`

```go
nums := []int{2, 3, 4}
for i, n := range nums {
    fmt.Println(i, n)
}
```

Результат:

```text
0 2
1 3
2 4
```

`i` — номер элемента; `n` — значение элемента. Если номер не нужен:

```go
for _, n := range nums {
    fmt.Println(n)
}
```

`_` означает **не использовать это значение**.

### Остановить или пропустить повторение

```go
for i := 1; i <= 5; i++ {
    if i == 3 {
        continue // пропустить i=3, перейти к следующему повторению
    }
    if i == 5 {
        break // выйти из цикла
    }
    fmt.Println(i)
}
```

Вывод: `1`, `2`, `4` на отдельных строках.

### Вложенные циклы: прямоугольник

```go
package main

import "fmt"

func main() {
    for row := 0; row < 2; row++ {
        for col := 0; col < 3; col++ {
            fmt.Print("*")
        }
        fmt.Println()
    }
}
```

Вывод:

```text
***
***
```

Внешний цикл — строки, внутренний — символы внутри каждой строки. Для рисунка из 3 строк по 4 звёздочки поменяй `row < 3`, `col < 4`.

## 6. Строки, символы и Unicode

```go
s := "Cat"
fmt.Println(len(s)) // 3 байта
```

**Важно:** `len(s)` для `string` считает **байты**, а не Unicode-символы! Для русских букв количество байтов может отличаться от количества букв.

Правильный подсчёт символов:

```go
count := 0
for range s {
    count++
}
```

Или:

```go
r := []rune(s)
fmt.Println(len(r)) // количество Unicode-символов
```

Перебор символов:

```go
for index, ch := range "Go!" {
    fmt.Printf("%d: %c\n", index, ch)
}
```

Для ASCII получим:

```text
0: G
1: o
2: !
```

Но у UTF-8 строки `index` — **номер начального байта символа**, а не обязательно номер буквы. Для позиций именно букв удобно сначала делать `[]rune(s)`.

Обратный порядок символов:

```go
r := []rune("Привет")
for i := len(r) - 1; i >= 0; i-- {
    fmt.Printf("%c", r[i])
}
```

`len(r)-1` — последняя доступная позиция, `i--` — шаг назад после каждого повторения.

### `z01.PrintRune`

Во многих заданиях Piscine вместо `fmt` требуется `z01`:

```go
package piscine

import "github.com/01-edu/z01"

func PrintStr(s string) {
    for _, ch := range s {
        z01.PrintRune(ch)
    }
}
```

`z01.PrintRune('A')` печатает **один символ** без автоматического переноса строки. `z01.PrintRune('\n')` печатает перенос строки. Для локальной проверки зависимость должна быть добавлена в модуль (`go.mod` + `go get`), а школьная среда может подключать её сама.

## 7. Срезы `[]int` и указатели

### Срезы

```go
nums := []int{5, 3, 7}
fmt.Println(nums[0]) // 5; индексы начинаются с нуля
fmt.Println(len(nums)) // 3 элемента
nums[1] = 10
nums = append(nums, 8)
fmt.Println(nums) // [5 10 7 8]
```

`[]int` — срез, `[3]int` — массив фиксированной длины 3. В заданиях часто используют именно срезы.

Посчитать количество чётных чисел:

```go
func CountEven(nums []int) int {
    count := 0
    for _, n := range nums {
        if n%2 == 0 {
            count++
        }
    }
    return count
}
```

Посчитать **сумму** чётных (а не количество):

```go
func SumEven(nums []int) int {
    sum := 0
    for _, n := range nums {
        if n%2 == 0 {
            sum += n
        }
    }
    return sum
}
```

### Указатели `&` и `*`

```go
a := 5
p := &a  // p хранит адрес a; тип p — *int
*p = 10  // изменить значение по адресу
// Теперь a == 10
```

- `&a` — взять адрес переменной `a`.
- `*p` — получить значение, находящееся по адресу `p`.
- `n *int` в параметрах функции — указатель на целое число.

Копия и указатель — не одно и то же:

```go
a := 5
b := a
p := &a
*p = 20
// a == 20, b == 5 (b хранит копию)
```

Указатель на указатель:

```go
a := 5
p := &a   // *int
q := &p   // **int
r := &q   // ***int
***r = 1  // a теперь 1
```

**Сколько звёздочек?** Столько переходов по указателям нужно до числа.

```go
    chars := []rune(s)

    }

}
```

### Atoi: учитывать плюс и минус

Файл `atoi.go`:

```go
package piscine

func Atoi(s string) int {
    if s == "" {
        return 0
    }

    sign := 1
    if s[0] == '-' {
        sign = -1
        s = s[1:]
    } else if s[0] == '+' {
        s = s[1:]
    }

    if s == "" {
        return 0
    }

    result := 0
    for _, ch := range s {
        if ch < '0' || ch > '9' {
            return 0
        }
        result = result*10 + int(ch-'0')
    }
    return result * sign
}
```

`"+12"` → `12`; `"-12"` → `-12`; `"++12"` → `0`. Это учебная версия: обработку переполнения `int` здесь не добавляли.

### SortIntegerTable: сортировка по возрастанию

Файл `sortintegertable.go`:

```go
package piscine

func SortIntegerTable(table []int) {
    for i := 0; i < len(table); i++ {
        for j := i + 1; j < len(table); j++ {
            if table[i] > table[j] {
                table[i], table[j] = table[j], table[i]
            }
        }
    }
}
```

`[5 4 3 2 1]` → `[1 2 3 4 5]`. Сортирует **исходный срез**, не возвращает новый.

## 9. Как написать функцию полностью: алгоритм

Задача: «Получить срез чисел и вернуть количество чётных».

**Сначала на бумаге:**

1. Что получаем? `nums []int`.
2. Что возвращаем? Одно целое число `int`.
3. Что считаем? Количество → `count := 0`.
4. Нужно ли перебрать всё? Да → `for _, n := range nums`.
5. Какое условие? `n % 2 == 0`.
6. Что делаем при успехе? `count++`.
7. Что вернуть? `return count`.

Полное решение:

```go
func CountEven(nums []int) int {
    count := 0
    for _, n := range nums {
        if n%2 == 0 {
            count++
        }
    }
    return count
}
```

**Проверка в `main.go`** (в отдельной папке практики):

```go
package main

import "fmt"

func CountEven(nums []int) int {
    count := 0
    for _, n := range nums {
        if n%2 == 0 {
            count++
        }
    }
    return count
}

func main() {
    fmt.Println(CountEven([]int{1, 2, 3, 4, 6}))
}
```

Команда: `go run main.go`. Вывод: `3`.

## 10. Частые ошибки новичка

| Неправильно | Правильно | Почему |
|---|---|---|
| `go run main go` | `go run main.go` | Имя файла включает точку |
| `if n = 2 {` | `if n == 2 {` | `=` — присвоить, `==` — сравнить |
| `if n => 10 {` | `if n >= 10 {` | Знак «больше или равно» пишется `>=` |
| `for_, n := range nums` | `for _, n := range nums` | Между `for` и `_` нужен пробел |
| `count + 1` | `count = count + 1` или `count++` | Вычисление нужно сохранить |
| `*n =+ 10` | `*n += 10` | `=+` присваивает `+10`, не прибавляет |
| `} \n else {` | `} else {` | В Go `else` должен быть на той же строке |
| `func Test(n int)` с `return 2` | `func Test(n int) int` | Объяви тип возвращаемого значения |
| `fmt.Println(...)` без `import "fmt"` | Добавь импорт | Пакет нужно подключить |
| `go run pointone.go` для `package piscine` | Запускай отдельный тест с `package main` | `piscine` — не самостоятельная программа |
| `I` вместо `i`, `Count` вместо `count` | Соблюдай регистр | Go различает строчные и заглавные буквы |

### Как читать сообщение об ошибке

Например:

```text
./main.go:8:5: syntax error: unexpected ...
```

- `main.go` — проблемный файл.- `8` — строка, где обнаружена проблема.
- `5` — позиция в строке.
- `syntax error` — ошибка синтаксиса; смотри указанную строку и иногда предыдущую.

Если терминал показывает `>` и ждёт продолжения, возможно, осталась незакрытая кавычка. Нажми `Ctrl + C` и введи команду заново.
